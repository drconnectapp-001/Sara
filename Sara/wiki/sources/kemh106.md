# Linear Inequalities

**Source:** [[raw/Mathematics/kemh106]] | **Date ingested:** 2026-05-12 | **Type:** book-chapter

## Summary

Chapter 6 extends equation-solving to inequalities — statements where one side is greater than or less than the other. Key rules: inequalities can be manipulated like equations EXCEPT when multiplying/dividing by a negative number (inequality sign reverses). The chapter covers one-variable inequalities (solution on number line), two-variable linear inequalities (graphical solution in plane), and systems of inequalities (intersection of solution regions).

## Key Points

- **Inequality types:** <, >, ≤, ≥ (strict vs non-strict)
- **Rules for inequalities:**
  - Add/subtract any quantity to both sides: inequality preserved
  - Multiply/divide by POSITIVE number: inequality preserved
  - Multiply/divide by NEGATIVE number: **INEQUALITY REVERSES**
- **Solution of linear inequality in one variable:** ax + b < 0 → x < –b/a (if a > 0); x > –b/a (if a < 0)
- **Solution set:** represented on number line; open circle for < or >, closed circle for ≤ or ≥
- **Interval notation:** (a,b) for open; [a,b] for closed; (–∞, a] etc.
- **System of inequalities:** solution = intersection of individual solution sets
- **Two variables:** ax + by < c defines a half-plane; boundary line ax + by = c
  - If strict inequality (<,>): dashed boundary line (not included)
  - If ≤, ≥: solid boundary line (included)
- **Graphical method:** shade feasible region satisfying ALL constraints
- **Corner point method:** optimal value of objective function occurs at a corner point of feasible region (preview of Linear Programming)
