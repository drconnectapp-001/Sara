# Electronic Configuration

## Definition
The distribution of electrons among the orbitals of an atom, following three governing rules: Aufbau principle, Pauli Exclusion Principle, and Hund's Rule.

## Why It Matters
Electronic configuration determines: valence electrons → bonding behavior, block classification in periodic table, magnetic properties, and anomalous stability (half-filled/fully-filled subshells).

## Three Rules

**1. Aufbau Principle** — fill lowest energy orbital first
- Energy order: 1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f ≈ 5d < 6p < 7s < 5f ≈ 6d
- (n+l) rule: lower (n+l) fills first; equal (n+l) → lower n fills first

**2. Pauli Exclusion Principle** — no two electrons can have identical set of all four quantum numbers
- Maximum 2 electrons per orbital (opposite spins ↑↓)
- Capacity: s=2, p=6, d=10, f=14

**3. Hund's Rule of Maximum Multiplicity** — in degenerate orbitals, electrons fill singly with parallel spins before pairing
- Example: C (1s²2s²2p²) has 2p electrons in separate orbitals, parallel spins

## Key Configurations

| Element | Z | Configuration |
|---------|---|--------------|
| H | 1 | 1s¹ |
| He | 2 | 1s² |
| C | 6 | [He]2s²2p² |
| N | 7 | [He]2s²2p³ (half-filled 2p) |
| O | 8 | [He]2s²2p⁴ |
| Ne | 10 | [He]2s²2p⁶ |
| Na | 11 | [Ne]3s¹ |
| Ar | 18 | [Ne]3s²3p⁶ |
| K | 19 | [Ar]4s¹ |
| **Cr** | 24 | **[Ar]3d⁵4s¹** (not 3d⁴4s²) |
| **Cu** | 29 | **[Ar]3d¹⁰4s¹** (not 3d⁹4s²) |
| Zn | 30 | [Ar]3d¹⁰4s² |

**Anomalous configurations (Cr and Cu):** half-filled (3d⁵) and fully-filled (3d¹⁰) are extra stable → one 4s electron promotes to 3d

## Magnetic Properties
- **Diamagnetic:** all electrons paired (e.g., Zn, Cu⁺)
- **Paramagnetic:** has unpaired electrons; attracted to magnetic field (e.g., O, Fe, Cr)
- Number of unpaired electrons determines degree of paramagnetism
