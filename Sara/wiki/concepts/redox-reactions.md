# Redox Reactions

## Definition
Reactions involving simultaneous oxidation (loss of electrons / gain of O / loss of H) and reduction (gain of electrons / loss of O / gain of H). Every redox reaction has both processes occurring at once — you cannot have one without the other.

## Why It Matters
Redox underpins electrochemistry, corrosion, combustion, biological metabolism, and industrial processes. For JEE it is calculation-heavy: oxidation number assignment, balancing, and E° interpretation are all numerically tested.

## Key Rules — Oxidation Numbers
- Free element: 0
- Monoatomic ion: equal to its charge
- O: −2 (except peroxides −1, superoxides −½, OF₂ = +2)
- H: +1 (exception: metal hydrides = −1)
- F: always −1
- Sum rule: neutral compound → sum = 0; ion → sum = charge
- **Fractional OS** (e.g., S in S₄O₆²⁻ = +2.5) are averages — the real structure shows multiple distinct integer states

## Four Types of Redox Reactions
| Type | Pattern | Example |
|---|---|---|
| Combination | A + B → C | 2Mg + O₂ → 2MgO |
| Decomposition | C → A + B | 2HgO → 2Hg + O₂ |
| Displacement | A displaces B from compound | Zn + CuSO₄ → ZnSO₄ + Cu |
| Disproportionation | one element simultaneously oxidised AND reduced | Cl₂ + 2OH⁻ → ClO⁻ + Cl⁻ + H₂O |

## Balancing Methods
1. **Oxidation Number Method**: identify atoms changing OS, equalise total increase = total decrease in oxidation number, then balance charges with H⁺/OH⁻ and H₂O
2. **Half-reaction (ion-electron) Method**: write separate half-equations for oxidation and reduction; balance each (atoms, then charge with H⁺ or OH⁻ + H₂O); multiply to equalise electrons; add

## Standard Electrode Potentials (E°)
- Measured vs. Standard Hydrogen Electrode (SHE): E°(H⁺/H₂) = 0.00 V
- More negative E° → stronger reducing agent; more positive E° → stronger oxidising agent
- Key values to memorise for JEE:

| Electrode couple | E° (V) |
|---|---|
| F₂/F⁻ | +2.87 |
| MnO₄⁻/Mn²⁺ | +1.51 |
| Cr₂O₇²⁻/Cr³⁺ | +1.33 |
| Cl₂/Cl⁻ | +1.36 |
| Cu²⁺/Cu | +0.34 |
| H⁺/H₂ (SHE) | 0.00 |
| Fe²⁺/Fe | −0.44 |
| Zn²⁺/Zn | −0.76 |
| Al³⁺/Al | −1.66 |
| Li⁺/Li | −3.05 |

## Daniell Cell
Zn | ZnSO₄ ‖ CuSO₄ | Cu — Zn oxidised (anode), Cu²⁺ reduced (cathode); electrons flow Zn → Cu through external wire; salt bridge maintains electrical neutrality.

## Redox Titrations
- KMnO₄: self-indicator; purple → colourless end point
- K₂Cr₂O₇: uses diphenylamine indicator
- Iodometric: starch-iodine complex gives blue colour; disappearance at end point
