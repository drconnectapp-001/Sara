# Hydrocarbons

## Definition
Compounds containing only carbon and hydrogen. Classified into saturated (alkanes), unsaturated (alkenes, alkynes), and aromatic (benzene and its derivatives). Each class has characteristic structure, reactions, and mechanisms.

## Why It Matters
Highest JEE-weightage organic chapter. Tests: Markovnikov/anti-Markovnikov reasoning, ozonolysis product identification, EAS directive effects, Hückel aromaticity, conformational analysis, and preparation methods.

---

## Alkanes (CₙH₂ₙ₊₂)
- sp³ carbon; tetrahedral (109.5°); C–C = 154 pm; C–H = 112 pm
- C1–C4: gases; C5–C17: liquids; C18+: solids; non-polar (van der Waals only)
- **Branching lowers bp** (smaller surface area, weaker vdW)

### Conformations of Ethane
- **Staggered**: dihedral = 60°; minimum torsional strain; most stable
- **Eclipsed**: dihedral = 0°; maximum torsional strain; least stable
- Energy difference: 12.5 kJ mol⁻¹; rotation is nearly free at room temperature
- Drawn as: Sawhorse projection (3D perspective) or Newman projection (end-on)

### Chemical Reactions
| Reaction | Conditions | Products/Notes |
|---|---|---|
| Halogenation | hν, free radical chain | Cl₂ > Br₂; 3° H > 2° H > 1° H (selectivity) |
| Combustion | excess O₂ | CO₂ + H₂O; incomplete → carbon black |
| Controlled oxidation | Cu/523K/100 atm | CH₄ → CH₃OH; Mo₂O₃ → HCHO |
| Isomerisation | anhy. AlCl₃/HCl | n-alkane → branched alkane |
| Aromatization | 773K, V/Mo/Cr oxide on Al₂O₃ | n-C₆+ → benzene + H₂ |
| Steam reforming | Ni, 1273K | CH₄ + H₂O → CO + 3H₂ (industrial H₂) |
| Pyrolysis/cracking | high T, free radical | higher → lower alkanes + alkenes |

**Free radical halogenation mechanism**: initiation (Cl–Cl homolysis by hν) → propagation (Cl· + RH → HCl + R·; R· + Cl₂ → RCl + Cl·) → termination (radical coupling)

### Preparation
- Unsaturated HC + H₂ (Pt/Pd/Ni catalyst)
- Alkyl halide + Zn/H⁺
- **Wurtz reaction**: RX + 2Na + XR → R–R + 2NaX
- **Decarboxylation**: RCOONa + NaOH/CaO → R–H + Na₂CO₃
- **Kolbe's electrolysis**: electrolysis of sodium carboxylate → alkane

## Alkenes (CₙH₂ₙ)
- C=C: one σ (sp²–sp², 397 kJ mol⁻¹) + one π (p–p lateral, 284 kJ mol⁻¹)
- C=C bond length: 134 pm; all atoms around C=C are **planar** (120°)
- π bond restricts rotation → **geometric (cis/trans) isomerism**: each doubly bonded C must have two different groups
- cis more polar (dipole moments add); trans has higher mp (more symmetric packing)

### Addition Reactions
| Reaction | Rule/Reagent | Product |
|---|---|---|
| H₂ + Pt/Pd/Ni | — | alkane |
| X₂/CCl₄ | — | vicinal dihalide; decolourises Br₂ (test) |
| HX | **Markovnikov**: H⁺ → C with more H; X⁻ → more substituted C | reasons: more stable carbocation intermediate |
| HBr + peroxide | **Anti-Markovnikov** (Kharasch effect) — free radical mechanism; only HBr, not HCl/HI | Br to less substituted C |
| H₂O + H⁺ | Markovnikov product | industrial alcohols |

### Oxidation
- Cold, dilute, alkaline KMnO₄ (**Baeyer's reagent**): purple → colourless; diol product; test for unsaturation
- Hot, conc. KMnO₄: cleaves double bond → ketones / carboxylic acids / CO₂
- **Ozonolysis** (O₃/Zn–H₂O): cleaves C=C; identifies double bond position from aldehyde/ketone products

### Preparation
- Alkynes + Lindlar's catalyst → **cis** alkene; Na/liq. NH₃ → **trans** alkene
- Alkyl halides + alc. KOH (β-elimination): rate I > Br > Cl; 3° > 2° > 1°
- Vicinal dihalides + Zn (dehalogenation)
- Acid dehydration of alcohols (conc. H₂SO₄, β-elimination)

## Alkynes (CₙH₂ₙ₋₂)
- C≡C: one σ + two π bonds; sp hybridised; linear (180°); C≡C = 120 pm
- **Acidic character**: terminal alkyne sp C–H is significantly acidic (reacts with Na, NaNH₂)
  - AgNO₃/NH₃ → white ppt (AgC≡CR) — distinguishes terminal alkynes from alkenes
  - Cu(NH₃)₂Cl → red ppt

### Reactions
| Reaction | Conditions | Product |
|---|---|---|
| H₂ | Lindlar's → cis alkene; Na/liq. NH₃ → trans alkene; excess Ni → alkane | |
| X₂ | stepwise | dihalide → tetrahalide |
| HX | Markovnikov twice → gem dihalide | vinyl halide intermediate |
| H₂O | H₂SO₄/HgSO₄ | enol → tautomerises: HC≡CH → CH₃CHO; others → ketone |
| trimerisation | 873K, Cu/activated charcoal | 3 HC≡CH → benzene |

**Preparation**: CaC₂ + H₂O → HC≡CH + Ca(OH)₂ (industrial acetylene)

## Benzene and Aromaticity

### Structure
- Resonance hybrid of two Kekulé structures; all C–C = 139 pm (between single 154 and double 134)
- **Hückel's rule**: aromatic if cyclic + planar + fully conjugated + **4n+2 π electrons** (n = 0, 1, 2…)
- Benzene: 6 π electrons (n=1) ✓; prefers **substitution over addition** to retain aromaticity

### Electrophilic Substitution (EAS) Mechanism
Electrophile (E⁺) attacks π system → σ complex (arenium ion, ring loses aromaticity) → deprotonation restores aromaticity

| Reaction | Electrophile | Reagent |
|---|---|---|
| Halogenation | Br⁺ | X₂ + FeBr₃ or AlCl₃ |
| Nitration | NO₂⁺ (nitronium) | conc. HNO₃ + conc. H₂SO₄ |
| Sulphonation | SO₃ | oleum; reversible |
| Friedel-Crafts alkylation | R⁺ carbocation | RX + AlCl₃ |
| Friedel-Crafts acylation | RCO⁺ acylium | RCOCl + AlCl₃ |

### Directive Effects of Substituents
| Type | Examples | Effect on ring | Position |
|---|---|---|---|
| Activating, o/p directors | –OH, –NH₂, –NHR, –OR | +R donation | ortho + para |
| Deactivating, o/p directors | halogens | +R > −I (position selectivity) | ortho + para |
| Deactivating, meta directors | –NO₂, –CN, –CHO, –COOH, –SO₃H | −R withdrawal | meta |
